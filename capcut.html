Switching to English CapCut

JianyingPro (剪映专业版) and CapCut are the same editor from the same company — CapCut is the international English build. Your editing skills and most of your drafts carry over.

1What changes, in one table

Now (JianyingPro)With CapCut
Chinese menus onlyFull English interface, switchable
Account required for export / cloudLocal editing and export work without signing in on most versions
Stock library with searchSame stock video / audio / sticker library, searched in English
Effects, filters, transitionsSame effects, same names in English
Drafts in com.lveditor.draftIdentical folder layout — drafts can often be copied across

2Install

  1. Go to capcut.com/download and take the Windows installer.
  2. Run it, finish setup, and open CapCut.
  3. Leave the JianyingPro folder you already have untouched until step 4 — you may still want it.

If capcut.com says unavailable in your region, the desktop build is still distributed on the official download page — retry from a different network. Do not use “cracked Pro” builds: they replace exactly the files that make drafts and exports work.

3Switch the interface to English

  1. In CapCut, click Settings (gear icon, upper-right of the home screen).
  2. Open General → Language.
  3. Pick English, then restart the app — the change only shows after a restart.

The home screen in Chinese for this one step: 设置 (Settings) → 通用 (General) → 语言 (Language) → English.

4Bring your existing drafts over

Both apps keep projects in a folder with the same name, so a copy usually opens:

From: %LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft
To:   %LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft
  1. Close both apps.
  2. Back up the CapCut projects folder first (copy it next to itself).
  3. Copy one draft folder — not all of them — into the CapCut folder and open CapCut.
  4. If it opens, the rest will too. If it shows missing media or effects, keep that draft in JianyingPro and rebuild it in CapCut.

Draft files carry a version number. A draft made in a much newer JianyingPro than your CapCut may refuse to load — that is expected, not a broken copy.

6Stock video: search, rename, tags

Inside a project, open Media → Stock videos (or the Stock tab). Type what you want in English — “city timelapse”, “ocean waves” — and the clips appear and can be dragged straight onto the timeline. That is the searchable stock library your JianyingPro build has.

For your own clips, CapCut's media panel has folders but no tags. The workflow that gets you close:

  • Keep one folder per topic, e.g. Stock\Beach, Stock\City.
  • Rename files as you save them, putting the tags in the name: beach_sunset_drone_4k.mp4.
  • In the media panel use the search field to filter by that name — typing “beach” or “drone” finds them.

True per-clip tagging with its own search box does not exist in CapCut. If you need it, it is a separate small web library — say the word and I will build it in this project.

7What still asks for an account

  • Works without signing in: importing media, editing, effects, local export, drafts on your PC.
  • Asks for an account: cloud sync, team/shared space, some AI features, and on some versions the export button itself.
  • If export shows “Sign in required”, that is CapCut's own gate and it cannot be edited out of the installer — sign in, or export from JianyingPro for that one project.

8If CapCut will not install in India

CapCut's mobile apps are not distributed in India, and the desktop download sometimes refuses the region. Two English, login-free fallbacks that read the same drafts workflow:

  • DaVinci Resolve — free desktop editor, English, offline, no account, far more capable than CapCut for cutting.
  • Shotcut — free, open source, English, no account.

Neither imports your JianyingPro drafts; you would rebuild the timeline there.
